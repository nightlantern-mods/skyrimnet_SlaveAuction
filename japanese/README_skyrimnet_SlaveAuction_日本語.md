# SkyrimNet 奴隷オークション

リフテン近くの石造りの地下で開かれる、秘密の奴隷オークションです。スタッフ、12 人の買い手、捕まった人たちが SkyrimNet の AI で喋るので、毎回違う夜になります。

成人向けの MOD です。監禁とヌードの表現があります。

## 0.1.0 を使ったことがある方は、修復を 1 回行ってください

**0.1.0 は、SkyrimNet の他の MOD 向けの設定を書き換えていました。** 競売のたびに、他の MOD が SkyrimNet に追加している行動の一部（拘束具、誘拐、戦闘、着替えなど。最大 39 種類で、導入している MOD の行動だけが対象）の待ち時間を書き換え、SkyrimNet の設定 `Actions.yaml` に保存していました。そのため、それらの MOD の動きが競売の外でも変わります。

- **0.1.0 で競売を行った方:** この版に更新してから、別配布の **SkyrimNet Actions Repair** を、ゲームを閉じた状態で 1 回だけ使ってください。使い方は同梱の README にあります。0.1.1 に更新したときに使った方は、もう一度使う必要はありません。
- **0.1.1 以降から使い始めた方、0.1.0 で競売をしていない方:** 修復は不要です。0.1.1 から、この MOD は SkyrimNet の設定に一切触れません。

## 必須 MOD

- SKSE64
- SkyrimNet（AI モデルの設定が必要です）
- SkyUI
- PapyrusUtil
- UIExtensions

ZaZ Animation Pack は任意です。なければ、競りに出された人は十字架に拘束されず、舞台に立ったままになります。入れる場合は、powerofthree's Papyrus Extender も必要です。

## 導入

Mod Organizer 2 か Vortex でアーカイブを導入し、言語を選びます。サンプルは任意で、初期状態ではどれも選ばれていません。導入済みのセーブでも使えます。

## 遊び方

地図の**地下競売場**（リフテンの近く）へ行きます。最初の部屋に受付がいます。

### 自分が売られる

1. 受付が勧める酒を飲みます。近くのフォロワーと一緒に、裸で檻の中で目を覚まします。
2. 見張りに話しかけて、次に舞台に出す人を選びます。
3. 全員が売れたあとの結末は、導入している MOD で変わります。出口 MOD があればその場所へ移り、なければ解放戦線が突入します。

### フォロワーを売る、買い戻す

1. 受付に、自分は飲まずフォロワーに飲ませると伝えます。1 人か全員を選びます。
2. 競売場へ入り、見張りに話しかけて競りに出します。
3. 舞台に誰かがいる間は、入札キーで価格を 100 ゴールド上げられます。主人公が金額を喋ります。木槌の前に、最後の入札の機会があります。

| 落札者 | 結果 |
|---|---|
| 自分 | 落札額を払うと、落札の直後からまたついて来ます。 |
| 他の買い手 | 自分で出品した場合だけ、落札額の半分を受け取ります。売れた直後から、受付で落札額の 1.5 倍で買い戻せます。 |

自分のいない所でさらわれたフォロワーは、ゲーム内で 3 日間檻で待ち、そのあとで売られます。競売場で戦闘を始めると競売は中止になり、フォロワーは解放されて買い手は逃げます。

## 設定（MCM）

- **出口の決め方：** 重みに従ったランダムか、1 つに固定か。種類ごとに決めます。
- **出口の一覧：** 出口ごとの有効と無効、重み。
- **入札キー：** 標準は K です。シフトキーを含められます。同じキーを使う他の MOD も、シフトキーの有無を確認していなければ反応します。
- **売られるまでの日数**と、**買い手の上限額**。
- **読み込めない定義：** 読み込めなかった出口の定義と、その理由。

## サンプル

| サンプル | 内容 |
|---|---|
| 入口：戦闘敗北 | 人型の敵に負けると、死なずに売られます。ほかの敗北系 MOD と同時には使えません。 |
| 入口：就寝中の誘拐 | 屋外、宿屋、ダンジョンで眠ると、フォロワーがさらわれることがあります（標準は 25%）。 |
| 入口：袋詰めの引き渡し | Diary of Mine が必要です。袋詰めにした人を受付の部屋で縛った状態で取り出し、受付に引き渡すと競売にかけられます。他の買い手が落札すると、落札額の半分を受け取ります。 |
| 出口：鉱山 | 売られると、鉱山で働いて脱出します。他の買い手に売られたフォロワーは、鉱山で落札額の 1.5 倍で買い戻せます。 |
| 出口：馬車で町へ | 競売のあと、落札したフォロワーと一緒にリフテンの馬屋の前へ着きます。 |
| 出口：借金を背負って解放 | 金融屋が席に着き、あなたが買わなかった人をすべて落札します。落札された人は、落札額の 3 倍の借金を背負って、すぐに解放されます。フォロワーはあなたの元へ戻り、それ以外の人は家へ帰ります。借用書台帳が必要です。 |
| 追加 MOD：借用書台帳 | どの MOD からでも NPC に借金を負わせられる仕組みです。借用書を持たせ、ジャーナルで最大 10 人まで追跡できます。上の出口と一緒に導入されます。 |

プレイヤーが売られたときの出口を入れると、解放戦線の結末は起きません。見たいときは、MCM でその出口を無効にしてください。

## 注意

- **動作確認は Nether's Follower Framework（NFF）の環境だけで行っています。** フォロワー管理 MOD のないバニラのフォロワーなど、ほかの環境では確認していません。
- **バニラのフォロワーは、捕まっている間に解雇されることがあります。** プレイヤーを含まない競売では、フォロワー管理 MOD のワープで戻らないよう、捕まったフォロワーを待機状態（`WaitingForPlayer` = 1）にします。バニラでは、待機中のフォロワーはプレイヤーから離れてゲーム内で 3 日たつと解雇されます。そのあとで買い戻したときは、もう一度仲間に誘う必要があるかもしれません。
- **売られたフォロワーは、NFF の一覧に残ります。** 他の買い手に売られたフォロワーは同行しなくなりますが、NFF の管理からは外れません。
- **捕まるのは、プレイヤーの近くにいるフォロワーだけです。** 範囲は約 60 メートルで、人数は最大 10 人です。それ以外のフォロワーは、他の MOD が競売に名指ししない限り捕まりません。
- **メニューを開いている間は、競売も止まります。** SkyrimNet のセリフもスクリプトも待ちます。
- **AI が応答しないときは、** セリフなしで競売が進みます。セリフ 1 つにつき最大 20 秒待つので、止まって見えることがあります。そのときは SkyrimNet のログで、モデルの利用枠切れやタイムアウトを確認してください。
- **AI が金額を言い間違えることがあります。** 喋った金額が実際の入札額とずれることがたまにあります。通知の金額が正しい金額です。
